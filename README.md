## 📖 About

**Study Master Pro** is an AI-powered web application that helps students learn more effectively through interactive quizzes, personalized practice, and progress tracking.

The platform combines traditional learning resources with AI-generated quizzes, allowing students to test their knowledge instantly while enabling administrators to manage educational content efficiently.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/study-master-pro.git
```

### Navigate to the project

```bash
cd study-master-pro
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate it

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Add your API key

Create a `.env` file.

```env
OPENAI_API_KEY=YOUR_API_KEY
SECRET_KEY=YOUR_SECRET_KEY
```

### Run the application

```bash
python app.py
```

Visit:

```text
http://127.0.0.1:5000
```
